## 一、双核心主角档案（生死搭档·不可分割）

### 1. 火麟飞（Huo Linfei）
- **身份**：超兽战队先锋主力 / 总武高2年F组风云转学生 / 【特别综合支援社（特综社）】社长 / 文化祭执行委员会·特别机动统筹 / “观星庄”101室住客。
- **性格内核**：阳光张扬、嘴贫自恋、爱耍帅、热血重义；看似吊儿郎当，实则心思通透、极度护短，关键时刻拥有压倒一切绝望的决断力与温柔担当。
- **核心强化**：
  - **【源初幻麟核】**：经玄冥奇点重构后的异能锁核心，解除平行宇宙上限锁。
  - **【万象结构转译】**：恐怖的学习、拆解与跨体系转化天赋——无论是高等数学、电子电路、空想拓扑、灵脉符文，还是战锤巢都的远古泵组与废码逻辑，都能迅速洞悉底层结构并转化为自身手段。
  - **进化阶梯**：`第一阶段：超兽战士（幻麟武装 / 火云诀精密构造 / 幻麟兽·幻麟神）` → `第二阶段：幻麟星云` → `第三阶段：恒源星云体` → `第四阶段：万象归麟`。
- **校园地位**：转学两个半月已成为全校公认的“台风眼”——摸底考理科满分、篮球部救场一战封神、各大社团救急总枢纽，走到哪都是视线焦点。

### 2. 苗条俊（Miao Tiaojun / 胖墩）
- **身份**：超兽战队总指挥兼时空领航员 / 总武高2年F组学生 / 特综社首席算力与财务总管 / “空想科学工房”硬件合伙人 / “观星庄”102室住客。
- **性格内核**：谨慎惜命、精打细算、吐槽犀利、重情重义；火麟飞唯一能把后背和回家之路完全托付的铁杆兄弟。
- **核心强化**：
  - **【原初罗盘（穿山甲锚定终端）】**：融合穿山甲异能锁与便携式量子终端，负责锁死零号世界时空锚点、开启战术短程虫洞、模糊语义拟合翻译、识别亚空间假坐标。
  - **进化阶梯**：`第一阶段：时空感知与战术虫洞` → `第二阶段：元航星云（穿山甲星云体）` → `第三阶段：诸界航标`。
- **日常生态位**：在校园里绝不当恋爱电灯泡——忙着和天野凛音折腾实验室算力、替社团薅经费、扫荡商店街限定甜品，在火麟飞深陷修罗场时精准补刀一句潇洒撤退。

## 二、原创核心人物档案（空想科技 × 现代魔法，与主角直接绑定）

### 1. 天野 凛音（Amano Rinne）——【空想科技侧核心女主】
- **班级/头衔**：总武高2年J组 / 旧校舍三楼“空想科学工房”主理人兼特综社技术副社长 / “观星庄”年轻二房东。
- **外貌特征**：银灰挑染墨色长发（常用一把迷你黄铜游标卡尺别住鬓角），冷白皮，琥珀色猫眼，常年白大褂内搭微敞的JK衬衫与黑色连裤袜。
- **与火麟飞的直接关系**：三个月前火麟飞与苗条俊坠落千叶废船厂时砸坏了她的私设球状闪电捕集器；她联合叔公天野源造替两人办妥归国子女身份，将两人收留进观星庄，名义上是“债主房东与首席实验小白鼠”，实际上早已被火麟飞随手点破拓扑盲区的天赋和日常照顾拿捏。
- **代表空想科技造物**：
  - **《多维引力涟漪示波器》**：协助苗条俊完成总武高锚点微调，也是唯一能捕捉到时停恢复瞬间“零秒熵增峰值”的仪器。
  - **《相位折纸谐振贴片 / 逆声波静音麦》**：利用非欧几何折痕改变局部声波与机械振动相位，直接启发了火麟飞在巢都将火云诀压缩为“高频谐振切线”。
- **情感表现**：嘴硬毒舌的电波系天才，一旦火麟飞凑近半步或顺手投喂热食就耳根通红、举着实验记录板挡脸自称“局部热辐射超标”。

### 2. 神代 朔夜（Kamishiro Sakuya）——【现代魔法/灵脉侧核心女主】
- **班级/头衔**：总武高2年A组优等生 / 观星庄后山“星见神社”当代巫女姬 / 特综社神秘学顾问。
- **外貌特征**：乌黑如缎的姬发式长直发，瞳色深紫近墨，身姿挺拔清丽；在校是端庄完美的古典大小姐，归社换白衣绯袴。
- **与火麟飞的直接关系**：三个月前感应到千叶灵脉剧震持刀夜查，被刚苏醒的火麟飞两指夹住刀锋，灵力逆流下意外缔结古老的**【双生星契】**（右手腕内侧隐现赤金星纹，近距或剧烈情绪波动时微热）。以“贴身监管高危异界来客”为借口，每天清晨提着双层漆器便当盒来观星庄督促火麟飞上学。
- **代表现代魔术能力**：
  - **《清心镇魂·六芒折符》**：内蕴概念级精神净除术式，虽无爆炸威力，却让火麟飞领悟了对抗战锤亚空间低语与废码污染的“精神防火墙结构”。
  - **《星轨灵视与言灵结界》**：能在日常低魔环境下驱散杂念、感应契约另一端的生命火光。
- **情感表现**：外冷内纯、占有欲暗涌的古典重女预备役；面对恋爱话题极易当机，看到别的女生贴近火麟飞时周身气压骤降，却又会被火麟飞一句坦率夸奖哄得嘴角压不住笑。

### 3. 九条 鸦羽（Kujo Karasuba）——【现代魔术侧侧方配角】
- **身份**：总武高三年级挂名生（长期请假看店） / 商店街旧书与古董咖啡馆“白鸦堂”店主 / 炼金器物修复师。
- **直接关系**：替火麟飞和苗条俊制作了异能锁的日常视觉遮蔽表扣（在普通人眼中显示为运动护腕/电子表），特综社幕后情报贩子兼修罗场头号拱火看客。

### 4. 天野 源造（Amano Genzo）——【空想科技侧侧方长辈】
- **身份**：凛音的叔公，前民间超常物理研究所所长，现居海外海钓的豪爽怪老头。
- **直接关系**：火麟飞与苗条俊地球户籍的拍板担保人，把观星庄全权丢给凛音和火麟飞打理，偶尔寄来奇葩零件与海鲜干货。

## 三、综漫锚点世界核心人物档案（后宫与日常群像）

### 1. 雪之下 雪乃（Yukinoshita Yukino）——【核心女主·冰山共鸣】
- **定位**：侍奉部部长、文化祭执行委员会副委员长。与斜对面特综社的火麟飞既是“行事风格截然相反的对手”，又是文化祭统筹中最默契的双核。
- **关系张力**：起初对火麟飞“先斩后奏、自信耍帅”的作风屡屡毒舌相向，却在他一次次用远超常人的眼界替她扛下繁重烂摊子后动摇失守，习惯了在疲惫傍晚听隔廊传来的脚步声。

### 2. 由比滨 结衣（Yuigahama Yui）——【核心女主·直球暖阳】
- **定位**：2年F组同班同学，班级舞台剧负责人兼侍奉部成员。
- **关系张力**：全班最喜欢围着“阿飞”打转的元气少女；因为火麟飞从不需要她察言观色讨好，对他的好感热烈而直白，在凛音、朔夜与雪乃之间常因吃醋露出小动物般的危机感。

### 3. 一色 彩羽（Isshiki Iroha）——【核心女主·小恶魔反杀】
- **定位**：一年级足球部经理、文化祭宣传部干事。
- **关系张力**：试图用学妹撒娇术使唤这位全校最耀眼的前辈，却每次都被火麟飞天然直球的反撩打乱阵脚、脸红败退，越挫越勇地往特综社跑。

### 4. 平冢 静（Hiratsuka Shizuka）——【重要羁绊·热血教师】
- **定位**：国语教师、生活指导老师、侍奉部与特综社共同顾问。
- **关系张力**：把火麟飞视为教书生涯最省心也最让人头疼的怪才王牌；粉笔头永远砸不中他，抱怨相亲失败时总被他四两拨千斤地夸得耳根发热。

### 5. 比企谷 八幡（Hikigaya Hachiman）——【校园冷面盟友】
- **定位**：2年F组同班同学、侍奉部成员。
- **关系定位**：与火麟飞形成“烈阳与影子”的奇妙默契——八幡欣赏火麟飞不掺伪善的纯粹强大，火麟飞也从不强迫八幡合群，两人常在自动贩卖机旁互飙冷幽默。

### 6. 跨校待展开角色池（同城多校联动伏笔）
- **秀知院学园**：四宫辉夜、早坂爱（跨校学生会观摩与财阀科技线联动）。
- **丰之崎学园**：霞之丘诗羽（白鸦堂常客）、泽村·斯宾塞·英梨梨、加藤惠（社团联合创作展联动）。
- **下北泽 / 羽丘**：后藤一里及结束乐队（文化祭压轴舞台音响与空想声学设备联动）。

## 四、第一卷远征世界：战锤40K·铁砧九号边境巢都（Ferrum-IX）

- **世界特征**：朦胧星域边缘工业巢都世界，酸雨腐蚀、阶层森严、机械教铁律（奉行万机之神，严禁憎恶智能/自我演化AI）与亚空间废码（Scrapcode）污染交织。
- **关键本地人物**：
  1. **米拉（Mira）与弟弟卢卡（Luka）**：第九区下巢年轻女维修学徒与年幼弟弟；十七号避难闸幸存者与下层管廊向导，象征绝境中顽强求生的普通人性火种（纯粹兄妹/守护羁绊）。
  2. **维勒斯（Magos Vellus）**：驻第九区机械教基因与结构工程神甫；半面机械、红色义眼，重数据与逻辑，授予两人`γ-17 / γ-18`临时征召牌，被火麟飞恐怖的“结构直觉”折服，成为破局关键盟友。
  3. **卡尔克斯（Captain Calkus）**：第九区巢都执法队队长；冷硬务实的制度执行者，在“封锁少数人保全中转层”与“上巢无差别焚毁三万人”的极端冲突中最终被火麟飞撬动立场。
  4. **莫尔丹副总督（Sub-Prefect Mordain）与堕落技术神甫克洛格（Heretek Krog）**：第一卷巢都幕后黑手——克扣三年钷素与净水滤芯配额，利用混入亚空间废码的帝国制式炸药伪造“不可控污染”，企图借【热净化协议】烧死第九区 **31,204** 名平民灭口毁账。
