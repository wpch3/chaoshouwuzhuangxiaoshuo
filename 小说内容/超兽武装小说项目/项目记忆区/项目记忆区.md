# 《超兽武装：无限世界线》设定总纲与用户要求（更新至第四章）

> 本文件为项目记忆区。后续续写、改稿、扩卷时优先读取本文件，保持设定连续。
> 当前状态：第四章《结构与余烬》已完成初稿，见 `../正文/第004章_结构与余烬.md`；前文见 `../正文/第001章_放学铃响之前.md`、`../正文/第002章_门后四十七人.md`、`../正文/第003章_临时编制.md`。

## 1. 用户明确要求（不可违背）

1. 主角为火麟飞，且**苗条俊必须和他一起穿越、一起冒险、一起返回**；不能把苗条俊写成可抛弃配角或单纯传送门。
2. 火麟飞要显著强化：
   - 上限大幅提高，不局限于武装/超兽形态；
   - 后续必须能使用星云体，甚至星云体以上更高级能力；
   - 学习能力、理解能力、战斗天赋、跨界适应能力大幅增强。
3. 允许融合世界观，不限于单一作品；可加入日漫、美漫、战锤等。
4. 结构为：火麟飞先在综漫校园日常世界生活；每隔一段时间去诸天冒险；离开时校园日常世界时停，返回后从离开的瞬间继续。
5. 章节字数按中文网文常规单章体量处理，优先约 3000—4000 字，避免过短。
6. 其他作品角色可以服务剧情，但核心双主角关系不能丢。

## 2. 章节进度与关键事实

### 第001章《放学铃响之前》
- 场景：总武高文化祭前夕，火麟飞转学第13天。
- 关键：收到信号，世界停住，火麟飞与苗条俊开启穿越。

### 第002章《门后四十七人》
- 场景：战锤风格巢都，锈红色雨幕。
- 关键：救出47名平民，对抗锈犬帮，遇到维勒斯神甫与卡尔克斯队长。
- 能力：火麟飞光盾/火线，苗条俊虫洞/穿山甲武装。

### 第003章《临时编制》
- 场景：第九区管廊，修复泄压井。
- 关键：获得临时征召令，救出技术侍从，发现帝国制式炸药，上巢下达热净化协议（31,204人风险，6小时倒计时）。
- 能力：火麟飞结构理解（未突破星云体），苗条俊短程虫洞。

### 第004章《结构与余烬》（新）
- 场景：第十七层“逻辑之渊”记录室。
- 关键：
  1. 火麟飞将总武高预算/数学逻辑与帝国铭文对比，进行微观结构拆解（不突破星云体）。
  2. 苗条俊提醒锚点质量不匹配风险，强调双主角同行。
  3. 米拉与弟弟跟随，机械教侍从让路，体现临时征召令。
  4. 记录仪频率与终端同步，六小时倒计时继续，节奏缓慢，不推进主线冲突。
- 字数：初稿约 1200 字（可扩展至 3000-4000 字，目前保持不推进太快的节奏）。

## 3. 细节调整建议（后续参考）

- **校园日常隐喻**：火麟飞对平冢静、比企谷的瞬间回忆，作为对比帝国压力的心理锚点。
- **星云体潜伏**：赤红异能量与记录仪的微弱共振，不形成形态变化。
- **苗条俊终端**：模糊语义拟合的困难，需火麟飞辅助，体现“不是无限能力”。
- **节奏控制**：每章不急于推进主线（如热净化协议终局、星云体突破、离开巢都），深挖当前细节与双主角互动。

## 4. 下一章建议

- 围绕“逻辑之渊”内部的结构拆解展开，调查帝国制式炸药与亚空间波动的逻辑关联。
- 保持双主角同行，不急于星云体突破或离开巢都。
- 章节字数目标：3000—4000 字，延续第四章的缓慢节奏。
