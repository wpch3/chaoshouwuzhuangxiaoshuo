# 第095章 半步之间，船长留出的归路

九月二十二日，星期二，下午三点。

观星庄后院的地面上，放着四块大小不同的木板。

火麟飞站在第一块板前，抬脚迈过去，又停在第二块板边。

“这算什么训练？”

“让你先看路。”凛音蹲在旁边，用粉笔在地上标出位置，“昨天是你说的，不能只顾扩大力量。”

“我以为今天能直接召唤幻麟神。”

“可以，但先把不需要召唤时能做的事做完。”

苗条俊抱着罗盘从屋里出来，身后跟着朔夜。她上午处理完神社的事，提前发消息确认有空，才带着几张符纸过来。

“后院外侧的标记检查过了。”凛音说，“记录仪也放好了。里面用临时折叠区，外面不放无关的人或东西。任何人觉得不对，立刻叫停。”

朔夜把一张浅色符纸交给火麟飞：“这是提醒你看边界的，不是替你承受力量。纸上亮起来的时候，要先确认自己在哪里。”

“朔夜老师今天教什么？”

“先看你能不能把昨天的光点停住。”

火麟飞接过符纸，指尖燃起一粒细光。光沿着她画的弯线走到边缘，缓缓停下。

他让它维持了几息，又将光送回起点。朔夜点点头：“没有忘。”

“我昨晚练过。”

“练了多久？”

“十分钟。”

苗条俊立刻举手：“我作证。他练完把纸夹进本子，没有烧我的枕头。”

“你以前的枕头也不是我烧的。”

“上次是你的火把窗帘吓得差点烧起来！”

凛音把记录板塞到苗条俊手里：“船长，开始前先核对。你自己说要把入口和场地边缘分开。”

苗条俊低头看了看今天的布置，神情也认真起来。

昨天在神社，他借两道小弧面接力送过纸团；真正展开训练场时，入口、场地和出口并不是纸上三条线。只要一处变形，就可能带动旁边的空间。

“今天我先开小场，确认边界稳定后再扩大。”他说，“外面留一个观察点，凛音看外侧，朔夜看火麟飞的状态。我自己盯入口和里面的变化。”

“火麟飞呢？”朔夜问。

“他负责不要把我的场地打穿。”

“我尽量。”

“不是尽量，是必须。”

“好，必须。”

苗条俊抬起手。罗盘上的光纹展开，先形成一圈薄薄的弧面，随后向内折叠。火麟飞能感觉到脚下空间轻轻一沉，后院仍在原处，前方却多出一片可供训练的独立区域。

“入口稳定。”苗条俊说，“先别召唤。”

他让火麟飞拿着一块木板走进去，沿边缘走半圈，再从另一侧退回。第一次很顺利，第二次经过入口旁时，弧面却随着板子移动轻轻晃了一下。

凛音看向仪器：“外侧没有超出标记，但入口变化比刚才大。”

苗条俊立刻收紧场地，没有继续扩大。

“是我换方向太快？”火麟飞问。

“不是你的问题。”苗条俊在罗盘上调出刚才的变化，“入口和场地靠得太近，我一调整里面的形状，外面的边就跟着动。”

他试着在两者之间留出一小段缓冲。第二次，火麟飞走过同样的位置，弧面只微微一闪。

“比刚才小。”凛音说。

“先记下来，还不能说已经稳定。”苗条俊让火麟飞再试一次，又自己走了一遍。确认两次都没有异常，他才转向火麟飞，“现在可以试幻麟兽。”

火麟飞踏入场地中央，抬起异能锁。

赤色光纹从腕间铺开，熟悉的兽影在光中凝聚。幻麟兽落地时，四足稳稳踩住地面，没有像刚恢复那天一样出现短暂的迟疑。

“先走。”苗条俊提醒。

火麟飞站在兽形一侧，控制它缓缓向前。他自己向相反方向移动，两边的步伐起初还算一致，走到转角时，幻麟兽的前足却晚了一拍。

“停。”火麟飞主动收住。

朔夜观察着他胸前的符纸：“刚才没有碰到边界。你是自己觉得不对？”

“我转身的时候，注意力全放到了我这边。它的脚跟着慢了。”

“那你刚才本来打算让它怎么走？”

“从右边绕过木板，再回到我旁边。”

“你不需要每一步都盯着它。”朔夜指向场地里的木板，“先想好它走过这块板以后在哪里停。你自己走的时候，给它留一点时间。”

火麟飞想起那粒在圆圈里停留的小光。他重新安排路线：幻麟兽绕右，自己绕左，两者在后方会合，中间不同时转向。

第二次，幻麟兽先动。他看着兽形越过木板，等前足落稳，自己才向另一边迈步。两者会合时，他的肩膀仍有些发紧，却没有再出现明显的停顿。

火麟飞没有立即让幻麟兽回到身边。他把地上的第三块木板当成需要避开的障碍，试着让兽形守在一侧，自己去另一侧取一只空木盒。

盒子不重，难的是他俯身时，幻麟兽也跟着低了一点头。火麟飞刚直起身，兽形又向前迈了半步。

“你刚才想让它动吗？”凛音问。

“没有。我想的是把盒子拿起来。”

“那它为什么跟着动？”

火麟飞回忆片刻：“我担心盒子后面有东西挡住它，刚才下意识看了它一眼。”

苗条俊在入口边说：“你把自己的担心也当成指令送过去了？”

“可能。”火麟飞将盒子放回原处，“再试一次。你们帮我看着它的脚，我先不让它移动。”

他重新弯腰。这一次，幻麟兽留在木板旁，头部依旧因他的注意力变化轻轻偏了一点，四足却没有移动。火麟飞拿起盒子，慢慢站直，再让它绕过障碍来到身边。

“它不是自己看见危险才走的。”他摸了摸兽形的赤红甲面，“是我分给它的意念不够清楚。”

“那也不是坏事。”朔夜说，“至少你现在能察觉到它为什么动。以后真有危险，就知道该怎么重新下令。”

火麟飞将盒子放到苗条俊手里：“船长，接货。”

“里面是什么？”

“空气。”

苗条俊掂了掂：“货物安全。下次申请运点心。”

“等你把入口和场地分开再说。”

“这可是两个训练项目，不能把本船长的补给跟成绩挂钩。”

“比昨天好。”凛音说，“但不要连续做太多次。你的肩背刚恢复。”

“再试一次神形？”

她看了一眼记录：“可以，范围不变。只做变形和移动，不加攻击。”

火麟飞转向幻麟兽，异能量沿着兽身纹路流转。兽首扬起，甲片依次收束、翻转；片刻后，幻麟神的双足落在场地中央。

“超兽武装，幻麟神。”

赤银色的身影站稳，胸口的纹路随火麟飞的呼吸亮起。苗条俊看着罗盘，确认场地边缘没有被撑动，才向他比了个手势。

“可以走。”

幻麟神迈出第一步。

火麟飞同时向左跨步，想与神形分开。他刚一移动，幻麟神的右臂就偏了一点，脚下的木板被甲面擦得转了半圈。

“停。”苗条俊喊。

火麟飞立即止住动作。幻麟神站在原地，右臂慢慢收回，没有碰到边界。

“刚才我让它向前，自己又往左。”火麟飞皱眉，“两边的重心不一样，比兽形难得多。”

“而且你自己的脚下有板。”凛音提醒，“你的目光全放在它的手上。”

火麟飞低头，发现自己的脚尖已经靠近另一块木板边缘。如果刚才再快一点，他自己反而会先失去平衡。

“那就从半步开始。”朔夜说。

火麟飞看向她。

“不是让你以后都只走半步。现在先让你和它都能站稳，再把剩下半步走完。”

苗条俊也说：“我这边做两段空间的时候，第一段出来要先有地方接。你这边也可以试试，让动作之间有个能重新判断的位置。”

“你们两个今天商量好教我？”

“是你自己说要请老师。”朔夜回答。

火麟飞笑了笑，重新站好。幻麟神先抬起一足，向前落下；他没有立即跟着转身，而是等神形的重心稳定，再迈出自己的半步。

两边都站住后，他才发出下一道指令。

幻麟神缓缓转向，右臂绕开木板。他自己也从左侧绕过，最后停在神形身旁。

动作不算快，也没有一拳一脚的爆响，却比刚才完整。

“成功。”苗条俊说。

“还不够快。”火麟飞望着自己的手。

“你想快到什么程度？”凛音问。

“至少在真正有人需要救的时候，我不用站着等它走完。”

“那就先把救人的动作拆开。”苗条俊说，“有时是你先去，有时是幻麟神先挡。不是每一次都要两边同时跨出一模一样的一步。”

火麟飞看向神形与自己之间的空地，点了点头。刚才拿木盒时，他一直想着让兽形和自己保持同样的速度；如果两边本来就有不同任务，也许不必勉强它们像镜子一样同步。

“下一次试的时候，先把各自要做什么说清楚。”他说。

“再试之前先休息。”朔夜把水放到场地边，“这个顺序也要说清楚。”

“先把这一遍记住。”凛音道，“你要的是能一直用的配合，不是只在今天碰巧走过去。”

火麟飞点头，没有强行再加速度。他正准备让幻麟神收回，苗条俊忽然抬起手。

“等等，我想试一次入口固定。”

“现在？”

“不是扩大。你们都不动，我把入口和里面的支撑再分开一点。要是读数不对，我马上收回。”

凛音检查了外侧标记：“可以试一小段。火麟飞和幻麟神都保持原位。”

苗条俊吸了一口气，手指沿着罗盘上的两道光纹缓缓划开。入口边缘原本与场地内壁相连，此刻中间多出一道极窄的过渡弧。

起初很稳。

随后，幻麟神脚下的地面忽然轻轻震了一下。

“停！”朔夜先喊出声。

火麟飞胸前的符纸亮起一线金光。苗条俊没有硬撑，立刻把新加的过渡弧收回，入口恢复到此前的状态。

震动随即消失。

凛音查看仪器：“外侧没有越界。里面刚才有一次短促的回弹。”

“是我切开得太快。”苗条俊盯着罗盘，“入口稳住了，但里面的支撑被我带动，往回拉了一下。”

火麟飞看向幻麟神的脚：“它刚才没动，是地面在动。”

“对。”苗条俊抹了把汗，“幸好只是小范围。”

他没有把那次回弹当成完成的能力，也没有因为失败就把整个想法划掉。两段空间接力能做，怎样在较大的场地里安全分离支撑，还需要更多测试。

“今天先收。”他决定。

火麟飞收回幻麟神，赤色光纹散去。他走出场地时，苗条俊仍维持着入口，等他双脚都踏回后院，才让空间弧缓缓闭合。

最后一点波纹消失，院子里只剩四块木板和粉笔线。

“我还以为你会要求再来一次。”凛音说。

“想过。”苗条俊坐到台阶上，“但刚才的问题还没弄清楚。硬来只是让大家陪我赌。”

火麟飞递给他一瓶水：“船长今天很稳。”

“本船长一直很稳。”

“昨天差点把梨核掉在记录纸上。”

“那是餐桌航线的意外。”

朔夜拿起火麟飞胸前的符纸，看了看发亮的位置：“刚才我的符只提醒了你注意边界。真正让场地停下来的是苗条俊，他收得很快。”

“我听见你喊停才收的。”苗条俊说。

“所以大家都听见了。”凛音把刚才的读数存好，“下一次我们先研究回弹，不直接加大场地。”

火麟飞望着地上的粉笔线，忽然抬手在其中一块木板旁点出金光。小光点绕着板角慢慢走了一圈，停在靠近入口的位置。

“你在做什么？”朔夜问。

“想看看我能不能在动起来的时候，也留意它。”

“那就先不要召唤幻麟神。”她站到他旁边，“你自己走，光点留在原地。等你能一边走、一边知道它在哪儿，再想别的。”

火麟飞迈过一块木板。光点轻轻晃了一下，没有熄灭。他转身时，光偏离了原来的位置半寸；朔夜没有替他扶正，只提醒他：“它动了。”

“我看见了。”

他放慢脚步，调整呼吸。光点一点点回到板角，亮度比开始弱，却仍然清晰。

“这样算不算分心？”

“算同时照顾两件事。”朔夜看着那粒光，“你刚才没有逼它一直不动，而是发现它偏了以后，让它自己回到那条线上。”

火麟飞又走了两步，最后停在她身边。光点终于熄灭，他却没有觉得可惜。

“下次再久一点。”

“下次也可以换一条线。”朔夜把符纸还给他，“力量不是只会按照一种走法前进。”

“你教我的东西，我会一直记着。”

朔夜轻轻一怔，随即抬起眼：“那要记得是我和爷爷教的基础，不许出去说自己已经学会神社所有的术。”

“放心。我会说，神代老师还不肯给我毕业。”

“因为你还要交作业。”

两人都笑了。院门外传来车轮碾过路面的声音，又渐渐远去；观星庄里，晚饭的香气从厨房飘出来。凛音已经收好记录仪，苗条俊蹲着擦掉地上的粉笔线，只把木板按大小重新叠好。

“吃完饭，我把刚才的回弹画下来。”他说，“不是答案，但下次不用从头猜。”

“我帮你拿纸。”火麟飞弯腰捡起最后一块木板。

“你的肩膀呢？”凛音问。

“搬这一块没问题。”

“那只搬一块。”

“遵命，房东。”

苗条俊刚抱起另一块木板，肚子就响了。

火麟飞听见，抬头看向厨房：“房东，船长的支撑线快断了。”

“那就先吃饭。”

苗条俊抱着木板往屋里跑：“本船长早就准备好了！”
