# 第020章 文化祭启动会与甩锅的委员长

九月十四日，星期一。

台风过后的新一周伊始，整座千叶市立总武高等学校从早自习起便笼罩在一股躁动兴奋的气氛之中——走廊公告栏贴出了鲜红醒目的《本年度十月文化祭（总武祭）节目申报与筹备委员会招集通知》。

中午午休刚一下课，**2年F组**教室里便围绕着“今年班展到底搞什么节目”吵成了热锅上的蚂蚁。

“要我说干脆弄个时尚可丽饼咖啡屋嘛！女生穿女仆围裙，男生穿白衬衫黑马甲当执事——你们想想要是让叶山还有后排的火麟飞同学穿上黑马甲站在门口迎宾，咱们F班的营业额绝对能把隔壁E班秒成渣！”

三浦优美子小团体里的海老名姬菜推了推鼻梁上的眼镜，双眼泛着危险的腐女绿光，连珠炮似的挥舞着手里的草稿纸，“如果有必要的话，还可以增设双人男执事壁咚特别菜单……”

坐在靠窗倒数第二排啃面包的比企谷八幡后背一阵恶寒，默默把椅子往墙角缩了半尺；后排的苗条俊倒是听得眉飞色舞：“双人执事？本总指挥这身富贵福相，穿燕尾服当大掌柜收钱绝对镇得住场子！”

“小俊当掌柜肯定超喜感哈哈哈哈！”由比滨结衣笑得前仰后合，偷偷回头瞄了一眼正靠在窗边翻看物理讲义的火麟飞，脑海里不自觉浮现出少年换上修身黑马甲端咖啡托盘的画面，小脸顿时微微发烫。

恰在此时，F班后门被轻轻敲了两下。

一色彩羽怀里抱着一叠刚印出来的文化祭宣传部报名表，笑吟吟地探进半颗毛茸茸的亚麻色小脑袋：“打扰啦各位前辈~请问我们特综社的火麟飞社长在吗？”

全班男生的视线唰地扫向后门，户部翔羡慕得捶胸顿足：“不是吧？！上周是A班的神代巫女送便当，今天连一年级人气第一的一色学妹都亲自跑来后门找人？！火麟飞老兄到底修了多少辈子的福气啊！”

火麟飞起身走到后门接过表格扫了一眼：“怎么，宣传部这么快就把你抓去当干事了？”

“谁让人家这么能干又可爱呢~”一色彩羽眨了眨杏眼，压低声音凑近半步提醒道，“下午三点五十在三楼大视听室开启动会哦前辈！我刚才路过C班走廊的时候，听见相模前辈正在跟小姐妹炫耀说今天要竞选执行委员长，还打算拉J组的雪之下前辈给她当副手干活呢——前辈待会儿可别睡着啦！”

“谢了，一色情报员，回头给你记一功。”

目送心满意足挥手跑开的小狐狸，火麟飞若有所思地挑了挑眉。

下午三点五十分，第四节课下课铃刚响过不久，教学本馆三楼的大视听会议室里便已坐满了来自全校三十多个班级与主要社团的代表。

火麟飞与苗条俊代表着上周五刚转正挂牌的【特综社】，坐在靠窗倒数第二排的宽敞位置上；斜前方两排则是代表【侍奉部】与 **2年J组** 双重身份出席的雪之下雪乃，而比企谷八幡则以“侍奉部留守看门”的借口成功逃过了这种大型现充集会。

“各位同学，安静一下，我们准时开会啦~”

讲台正中央，三年级的学生会长城廻巡温婉一笑，轻轻拍了拍麦克风试音；指导老师席位上，平冢静翘着二郎腿抱臂坐镇，目光不时在台下扫视一圈。

“今年十月下旬的文化祭，是三年级学长学姐们高中生涯最后一次大型祭典，按照往年惯例，执行委员会的核心职务将由二年级同学挑大梁担任。”

城廻巡拿起花名册，柔声问道，“首先是统筹全局的【文化祭执行委员长】一职，不知道在座的二年级代表里，有没有同学愿意自告奋勇出来锻炼一下自己呢？”

话音刚落，会议室中段 **2年C组** 的座位区里，一名留着微卷棕色中短发、长相还算清秀可人的女生便迫不及待地高高举起了右手，脸上挂着精心练习过的羞涩矜持笑容站起身来。

正是2年C组的相模南。

在原本的班级生态里，相模南一直想挤进叶山隼人与三浦优美子那样的顶级现充核心圈，却苦于自身既没有三浦的美貌气场、又没有雪之下的耀眼成绩，于是早早就盯上了“文化祭执行委员长”这块能在全校出尽风头、还能写进大学推荐信里的镀金招牌！

“那个……如果大家都不好意思开口的话，我想试着挑战一下自己！”

相模南双手握在胸前，声音甜腻地朝四周看了一圈，还特意往F班代表方向瞟了一眼，“虽然我个人经验可能还有些不足，但只要大家齐心协力，我相信一定能办出一届最棒的文化祭！”

和她同班的几个小团体女生立刻配合地鼓起掌来。城廻巡温和地点点头：“相模同学很有热情呢，如果没有其他竞争人选的话，委员长一职就暂定由相模南同学担——”

然而，还没等城廻巡把“任”字说完，刚刚享受完掌声虚荣的相模南眼珠一转，立刻按照自己昨晚盘算好的如意算盘，转身面朝斜后方端坐的雪之下雪乃，露出了一副楚楚可怜的求助表情：

“不过城廻学姐！文化祭涉及全校预算审批、舞台安全检查、外校来宾接待还有上百份物资排期表，我一个人肯定忙不过来的……我听说J组的雪之下同学成绩全校第一，办事又最认真负责了！能不能请雪之下同学担任我的【执行副委员长】，帮我把这些具体实务文件管起来呀？雪之下同学这么优秀，一定不会拒绝帮助同学吧？”

嗡——

台下顿时响起一阵窃窃私语。

后排的苗条俊听得鼻子都快气歪了，压低嗓门冲火麟飞吐槽：“好家伙！我苗条俊活了这么大，头一回见到把‘我要上台领奖出风头，苦活累活全归你背锅’说得这么清新脱俗的厚脸皮！你看她手边那摞刚从学生会领来的十几本空白台账，连塑封膜都没拆就准备全往雪之下桌上推了！”

前排，雪之下雪乃长长的睫毛微微一垂。

面对这种用“你这么优秀一定不会拒绝吧”织成的道德绑架大网，以她高傲要强、宁可把自己累垮也绝不肯当众说半个“不”字的性格，纤白修长的手指已经微微抬起，准备像往常无数次那样冷淡地独自接下这副吃力不讨好的千斤重担——

“啪。”

一只修长有力的大手，忽然从斜后方稳稳伸了过来，一根食指轻轻按在了相模南刚刚抱过来准备搁在雪之下桌面上的那摞厚重文件夹顶上！

相模南一愣，抬头对上一双明亮锐利得让她心头一慌的少年眼眸：“火、火麟飞同学？你干什么呀？”

全会议室六十多道目光，连同讲台上的城廻巡与平冢静，瞬间齐刷刷聚焦到了缓缓站起身的火麟飞身上！

雪之下雪乃也微微一怔，仰起那张清冷绝美的侧脸看向身旁站立的少年。

“相模同学刚才那番话，我听着稍微有点替你担心啊。”

火麟飞单手插兜，指尖轻轻敲了敲那摞足有半尺厚的实务台账，笑容温和爽朗，说出口的每一个字却像手术刀一样精准剥开了相模南那点小心思：

“所谓执行委员长，是统筹全局的第一责任人；副委员长只是协助监督，可不是替正职包揽全部实务的秘书。如果从筹备第一天起，预算、排期、安检、外联十几项核心工作全压在副委员长一个人肩上——那等到十月开幕式相模委员长上台致辞的时候，万一台下有人问起舞台功率是多少、应急通道有几条，你连数字都报不出来，岂不是要当着全校师生的面下不来台？”

“噗嗤——”后排几个早就看不惯相模南爱出风头的社团干部没忍住笑出了声。

相模南一张脸瞬间涨成了猪肝色，支支吾吾道：“我、我当然会看的！我只是觉得雪之下同学擅长文书工作，大家分工合作嘛……”

“分工合作这个词用得好！”

火麟飞顺杆一拍巴掌，根本不给相模南半点退缩滑头的余地，转身面向讲台上的城廻巡与平冢静，朗声提议道：

“城廻会长，平冢老师！既然今年筹备委员会任务繁重，光靠正副两位委员长肯定分身乏术。我们四零四室【特综社】上周刚承蒙学生会批复成立，正好出一份力——我建议将筹备实务一分为三：第一，各班级节目申报、宣传海报与开幕式流程跟进，由相模委员长亲自带领C班干事负责，每周五公示进度签字画押；第二，全校预算审核与规章统筹，由雪之下副委员长把关；至于第三块最跑腿费力的全校舞台音响电路搭建、体育馆场地调度与突发状况机动救火——由我担任【文化祭特别机动统筹】，率特综社全盘接手！”

干脆！利落！权责分明到连半粒沙子都掺不进去！

既把相模南想甩出来的三分之二脏活累活直接分走了一大半、并将剩下一半死死钉回相模南自己的签字责任田里，又替单打独斗的雪之下雪乃稳稳撑起了整片后方防线！

指导席上的平冢静嘴角高高扬起，第一个举手拍板：“我附议！有火麟飞和特综社接手硬体机动保障，老师我今年至少能少抽两条烟！城廻，你看呢？”

“完全赞成！”城廻巡笑逐颜开地拿起红笔在组织架构表上添上一栏，“那就这么定下来了！执行委员长相模南、副委员长雪之下雪乃、特别机动统筹火麟飞——请大家鼓掌通过！”

雷鸣般的掌声响彻整间大视听会议室！

相模南骑虎难下地抱着那半摞属于她自己必须签字负责的班级申报表，僵笑着坐回原位，再也不敢往雪之下桌上塞半页废纸；

而在热烈的掌声之中，火麟飞收回按在桌沿的手，坐回位置前，低头冲还在仰头看着他的雪之下雪乃眨了眨眼，压低声音笑道：

“这下公平了，雪之下副委员长。十月文化祭这艘大船，咱们四楼东西两家一人掌一半舵。”

雪之下雪乃怔怔看着少年转回后排的挺拔背影，胸口仿佛有什么坚硬多年的冰层发出一声极轻的脆响。

她缓缓低下头，白皙手指轻轻抚过笔记本边缘，在一片无人注意的喧闹掌声里，唇角极轻、极浅地向上弯起了一丝连她自己都未曾发觉的温柔弧度。
