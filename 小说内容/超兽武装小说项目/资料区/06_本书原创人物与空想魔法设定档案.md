# 本书原创人物与空想科技/现代魔法设定档案

> 本文件专门记录与主角火麟飞有直接生活、户籍、同居及契约绑定的原创角色设定，以及零号锚点世界“里侧微光”能力边界，与各作品官方考据文档配合使用。

---

## 一、里侧微光（空想科技 × 现代魔法）运行总则

1. **宏观和平抑止律**：总武高所在的千叶—东京湾都市圈受极强的“日常因果稳态场”保护，不存在灭世魔王、大规模超凡热战或破坏城市建筑的轰炸级法术/重武器。
2. **微观高概念演化**：
   - **空想科技侧**：绕开常规工程繁琐限制，利用非欧几何折痕、局部量子纠缠与声光相位干涉制造“日常功率极低、结构思路神乎其技”的奇物；
   - **现代魔法/灵脉侧**：处于神秘消退纪元，魔力总量无法呼风唤雨，但在灵魂契约、精神防污染净除、因果丝线感知与护符编织上达到极致精妙。
3. **与主线冒险的化学反应**：她们在前期不进入残酷异界送死，但她们的研究成果与护符拓扑能被火麟飞通过【源初幻麟核】转译为异界破局利器；同时她们是校园中最早通过“0.01秒熵增/星契余温”察觉火麟飞秘密的枕边与身边人。

## 二、原创核心角色详细设定

### 1. 天野 凛音（Amano Rinne）——【空想科技侧核心女主】
- **班级与职务**：总武高 **2年J组（国际教养班，与雪之下雪乃同班）** / 特别栋四楼西侧【空想科学工房】主理人 / 【特别综合支援社（特综社）】技术副社长 / 海滨二层公寓**“观星庄”年轻二房东**。
- **外貌记忆点**：墨色微乱长发间挑染几缕冷银色，鬓角常年别着一把迷你黄铜游标卡尺；冷白皮，琥珀色猫眼；白大褂内套微松JK衬衫与黑色连裤袜。
- **与火麟飞的直接关系**：三个月前火麟飞与苗条俊坠落千叶废船厂时砸毁她的私设球状闪电捕集阵列；她搬出叔公天野源造替两人办妥归国子女户籍，将两人收留进观星庄（101室火麟飞、102室苗条俊，二楼凛音自住），名义上是“债主房东与首席实验小白鼠”，实则生活饮食高度依赖火麟飞投喂。
- **代表空想奇物**：
  - 《多维引力涟漪示波器》：协助苗条俊锁死总武高时空锚点，并在第006章捕捉到 `16:17:01` 回归瞬间暴涨600倍的局部时间熵尖峰。
  - 《非欧折纸相位贴片》：消解礼堂驻波，并直接启发火麟飞在战锤巢都将火云诀压缩为“高频谐振切线”。
- **恋爱反差**：平时语速飞快、毒舌傲气的电波系怪才，一旦火麟飞凑近半步、夸奖她设计漂亮或看穿她偷吃宵夜，立刻大脑过载耳根爆红，举实验记录板挡脸嘴硬“局部散热模块故障”；嘴上嫌麻烦，关键时刻第一个拿针织开衫帮刚从战场归来的火麟飞挡住焦痕。

### 2. 神代 朔夜（Kamishiro Sakuya）——【现代魔法/灵脉侧核心女主】
- **班级与职务**：总武高 **2年A组（升学特进班，年级前三）** / 观星庄后山坡百年古社**“星见神社”当代唯一巫女姬** / 特综社神秘学顾问。
- **外貌记忆点**：乌黑如缎的姬发式长直发及腰，深紫近墨的清冷眼眸，仪态端庄凛冽如古典画卷；归社换白衣绯袴，袖间常带淡淡白檀冷香。
- **与火麟飞的直接关系**：三个月前感应到千叶灵脉剧震持仪式太刀夜查，被刚苏醒的火麟飞两指夹住刀尖，灵脉回流下意外缔结古老本命契约**【双生星契】**（两人右手腕内侧隐现赤金星纹，近距接触或剧烈情绪/跨界归来时滚烫共鸣）。以“贴身监管高危异界来客”为借口，每天清晨提着亲手做的漆器便当盒跨过石阶来观星庄叫火麟飞上学。
- **代表现代魔术**：
  - 《清心镇魂·六芒折符》：耗费三夜灵力织就的概念净除护符，在第004—005章替火麟飞预警亚空间废码炸药，并被火麟飞拆解演化为十米赤金六芒镇魂防火墙。
  - 《星轨灵视与清净结界》：感知契约另一端的吉凶波澜。
- **恋爱反差**：表面清冷端庄的高岭巫女，实则对现代恋爱套路极度纯情、占有欲暗涌的重女预备役；看到由比滨、一色或凛音贴近火麟飞时周身气压骤降，却会被火麟飞揉一下头发或夸一句羊羹甜度刚好哄得眉眼融化。

### 3. 九条 鸦羽（Kujo Karasuba）——【现代魔术侧侧方配角】
- **身份**：总武高三年级挂名幽灵部员 / 商店街旧书与古董咖啡馆**“白鸦堂”**年轻店主 / 现代炼金杂货修复师。
- **与主角的直接关系**：替火麟飞和苗条俊制作了异能锁的日常视觉遮蔽表扣（普通人眼中显示为暗红运动护腕/电子表）；特综社校外情报商兼修罗场头号看戏御姐，白鸦堂同时也是丰之崎学姐霞之丘诗羽的校外写稿据点。

### 4. 天野 源造（Amano Genzo）——【空想科技侧侧方长辈】
- **身份**：天野凛音的叔公，前民间超常物理研究所所长，现常年云游海钓的豪爽怪老头。
- **与主角的直接关系**：火麟飞与苗条俊地球归国子女合法身份的拍板担保人，放心把观星庄和自家侄孙女交托给火麟飞照看。
