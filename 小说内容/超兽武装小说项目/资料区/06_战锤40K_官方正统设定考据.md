# 《战锤40K》（Warhammer 40,000）官方正统设定考据（深度扩充版）

## 一、人类帝国宏观机构权限边界（严禁串权！）

1. **五大星域（Segmentae Majoris）**
   - **太阳星域（Solar）**：神圣泰拉与火星核心区；
   - **朦胧星域（Obscurus）**：北方边境，邻近卡迪亚与恐惧之眼外围，工业巢都、古老黑石遗迹与亚空间风暴频发（本书第一卷**铁砧九号巢都 Ferrum-IX** 所在扇区）；
   - **极限星域（Ultima） / 暴风星域（Tempestus） / 太平洋星域（Pacificus）**。
2. **行星本地执法队 vs 泰拉直辖星界法务部（核心区分！）**
   - **行星总督（Planetary Governor）**：只要按时缴纳**帝国什一税（Imperial Tithe：人口兵源、工业品、燃料矿产）**且不公开叛国投敌，在星球内部拥有自治权。
   - **行星本地执法队（Planetary Enforcers / Vigiles）**：效忠行星总督府的本地治安警察（如第一卷**卡尔克斯队长**），配发基础甲壳护甲、镇暴霰弹枪与电击盾牌，管辖下巢防暴与检疫，**无权逮捕或审判上巢总督府贵族官员**。
   - **星界法务部（Adeptus Arbites）**：**神圣泰拉直辖**的帝国最高铁腕司法军！成员全部出身忠嗣学院（Schola Progenium），终身不在母星服役以防裙带腐败。
     - **核心职阶**：**仲裁官（Arbitrator）** → **督察（Proctor）** → **高阶大法官 / 扇区司法元帅（Judge / Marshal，如第一卷高阶大法官瓦莱丽娅，统辖整颗行星乃至数个恒星系的巡回法务舰队与要塞，危急时亲自披甲空降督战，集法官、陪审团与行刑官大权于一身）** → **大宪章总长（Grand Provost Marshal，驻泰拉最高领主议会）**。
     - **标志性武装**：黑底金鹰精工甲壳甲/动力辅助甲、**处决者霰弹枪（Executioner Shotgun，可发射自动追踪热源的破甲寻的弹、凝固汽油弹或静止力场弹）**、**动力镇暴权杖（Power Maul）与高压压制电盾（Suppression Shield）**、半机械改造军犬**机械獒犬（Cyber-Mastiff）**，空降突击主力载具为**女武神突击运输炮艇（Valkyrie Airborne Assault Carrier）**。
     - **核心职权**：执行《帝国大法（Lex Imperialis）》，核查帝国什一税亏空，**拥有直接攻入总督宫殿逮捕乃至当场处决渎职叛乱总督/副总督的合法最高执法权**！
3. **审判庭（The Inquisition）与行商浪人（Rogue Traders）**
   - **审判庭**：分异形（Ordo Xenos）、异端（Ordo Hereticus）、恶魔（Ordo Malleus）三大修会。前期边境巢都贪腐废码事件先由星界法务部处置，不轻易降下灭星令；中后期可接触审判庭外围审讯官（Interrogator）。
   - **行商浪人王朝**：持有古老《贸易特许状（Warrant of Trade）》的世袭星际开拓贵族，合法雇佣异界奇人、持有奇异遗物（本书双主角对外完美掩护身份，也是第五卷重返战锤星域的核心盟友切入点）。

## 二、机械修会（Adeptus Mechanicus）正统阶位、武器与兵种细表

### 1. 万机之神三位一体与最高红线
- **三位一体**：万机神（Machine God）、欧姆尼赛亚（Omnissiah）、动力源（Motive Force）。
- **机魂（Machine Spirit）**：坚信机械内宿机魂，启停与排障需涂抹圣油、焚香、敲击律动音叉并吟诵二进制祷文（Lingua-technis）。
- **【最高红线】憎恶智能（Abominable Intelligence / Silica Animus）**：严禁任何无人类生物脑湿件、可自我演化的纯硅基AI！（苗条俊对外统一称【原初罗盘】为“脑波同步黄铜个人辅算星盘”）。

### 2. 技术神甫阶位与分支
- **阶位**：技术学徒（Tech-Acolyte，如**米拉**）→ 初级机械教士/引擎先知（Enginseer，如**托伦**）→ **逻辑/工匠/基因贤者（Magos，如维勒斯）** → 大贤者（Archmagos）→ 铸造将军（Fabricator-General）。

### 3. 标准武器与重型机兵考据（供战斗精确描写）
- **常见机械教/巢都重武器**：
  - **重型伐木枪（Heavy Stubber）**：大口径实弹重机枪，巢都自动炮塔与帮派常用重火力；
  - **电弧步枪 / 电弧爪（Arc Rifle / Arc Claw）**：释放高能蓝白闪电链，专克机械载具与重甲；
  - **磷火爆破枪（Phosphor Blaster）**：发射黏附燃烧的白磷化学火球，沾身难灭；
  - **等离子卡宾枪 / 巨炮（Plasma Caliver / Culverin）**：小太阳般的高温蓝白电浆球，过热有炸膛风险；
  - **爆燃武器（Volkite）**：火星古老热射线武器，令目标由内而外晶化爆燃。
- **护教军（Skitarii）**：半机械改造精锐士兵，分身穿兜帽长袍持电弧/伽马步枪的**护教军游侠（Rangers）**与头戴重辐射面罩持镭卡宾枪的**护教军先锋（Vanguard，周身带强辐射，普通人靠近会患辐射病）**。
- **卡塔弗隆重装战斗机仆（Kataphron Battle Servitors）**：下半身为重型坦克履带、上半身缝合巨人罪犯躯干的恐怖半生物兵器。分近战破甲型**破阵者（Breachers，配重型电弧爪+扭曲炮）**与远程重炮型**毁灭者（Destroyers，配等离子巨炮/重力炮+火焰喷射器）**。
- **卡斯特兰铁卫机兵 / 远古攻城自动机兵（Kastelan Robot / Siege Automaton）**：高达四至九米的上古遗留无智能重甲机器巨人，胸口设有**教条晶片插槽（Doctrina Wafers）**，必须由**数据铁匠（Cybernetica Datasmith）**手动更换晶片切换指令；一旦插槽被刺入**亚空间废码晶片**，便会化作不知疲倦的失控毁灭巨兽！
- **黑暗机械教恶魔引擎（Daemon Engines · 异端禁忌造物）**：黑暗机械教异端机工将亚空间恶魔灵魂强行锻铸进重型战争机器躯壳内的扭曲兵器，兼具厚重精金装甲与血肉再生能力，唯有摧毁其体内的**恶魔共生核（或以负向极性黑石断绝亚空间连接）**方能彻底击杀：
  - **噬魂毒蛛（Venomcrawler）**：六至八米长的蜘蛛型恶魔引擎，配备双联痛楚灵魂大炮与剖膛锯刃（第058章登场）；
  - **冥锻恶魔炮兽（Forgefiend）**：六至七米高的半人马/巨兽型远程火力引擎，双臂挂载高射速冥府重型自动炮或外质等离子炮；
  - **屠夫级/碎颅者超重型恶魔攻城机兵（Maulerfiend / Decimator Siege Engine）**：十至十八米高、重达百吨以上的攻城凶兽，配备热熔切割触须与攻城巨拳，专司撕裂要塞铁闸与地壳岩层！

## 三、亚空间废码与神圣奇物“黑石（Noctilith）”正统设定

1. **亚空间废码（Scrapcode）**：
   - 源自荷鲁斯大叛乱时期火星莫拉维克地库的恶魔逻辑病毒，以刺耳高频噪音或紫红乱码电讯传播，能在毫秒级感染沉思者、机仆与铁卫机兵，同时令无防护人类产生脑神经剧痛与幻听。
2. **黑石 / 夜石（Noctilith / Blackstone）——【极佳无污染跨界研究奇物！】**：
   - 战锤宇宙最神秘的上古非亚空间矿物（卡迪亚方尖碑核心建材），本身**绝对不含任何亚空间污染**。
   - **双向极性法则**：正向充能时可增幅灵能；而**负向极性（抑制态）黑石**则能令周围亚空间波涛彻底平息、压制废码与恶魔越界、稳固现实物理帷幕！大贤者贝利撒留·考尔亦在四处搜集黑石研究反亚空间屏障。
   - **本书应用锚点**：铁砧九号巢都远古地基深处若存有指甲盖至鸽卵大小的**天然负向极性黑石原矿碎晶**，既能在第一卷协助镇压废码源头，也属于100%安全无害、可供天野凛音与神代朔夜研究“相位现实稳固场”的顶级无污染学术奇物！

## 四、巢都地热构造、法务部战地法庭与机械修会“神圣有机派”正统考据（第067—094章剧情精进增补！）

1. **巢都能源心脏：中央地热热沉主井（Hive Heat-Sink）与巢底（The Sump）**
   - **正统构造（源自《涅克洛蒙达》官方巢都解剖学）**：每一座帝国巢都尖塔正中心都贯穿着一条宽达数百米至数公里、直插行星地壳之下的巨型塑钢垂直管道——**热沉主井（Heat-Sink）**，通过**热等离子捕获站（Thermal Plasma Capture Stations）**汲取地核岩浆热能，转化为全巢都工业与上巢贵族的电力；而下巢底层仅能分得逸散余温与昏暗照明，最底部则是废液汇聚与地基承重桩所在的**巢底毒沼层（Hive Bottom / The Sump）**。
   - **本书决战场景精准锚定**：下巢第九区地下 `-1100米` 的岩浆裂谷，正是铁砧九号**【九号副热沉地热捕获井箍阀（No.9 Auxiliary Heat-Sink Collar）】**所在地！一旦被“碎颅者”恶魔攻城机兵撕裂塑钢箍阀，三千度高压地幔热等离子与岩浆将顺着管道倒灌淹没整个第九区三万平民！
2. **机械修会“保留纯净人类肉身”的官方合法教义支撑——生物贤者与有机纯粹派（Magos Biologis / Organicists）**
   - **核心防穿帮依据**：外行常误以为机械教100%全员必须切肢换铁皮；实则在火星正统高阶秘仪（High Tech-Arcana）中，**生物贤者派（Magos Biologis / Genetor，连大贤者考尔亦自封此衔）与有机纯粹学派（Organicists）**明确主张：**“活体人类组织、基因与神经网络本身就是欧姆尼赛亚亲手锻造的最精密、具备自我修复能力的神圣有机机器（Organic Machine），盲目用粗糙金属切掉完美健康的原生器官，反而是对万机之神至高蓝图的亵渎！”**
   - **对女主米拉的关键意义**：第一卷战后火麟飞拦下传统派切肢礼、支持米拉保留100%纯净人类少女娇躯时，维勒斯贤者可正式援引**《火星生物贤者正典·神圣有机机器律》**为米拉完成正统受膏晋升——让米拉在帝国法理与火星教义上都**100%合法正统、无人敢扣异端帽子**！
3. **星界法务部战地最高法庭（Field Tribunal）与司法军管监护权**
   - 当行星总督/副总督犯下“贪墨帝国什一税（Exactis Extremis）+ 勾结黑暗机械教投放恶魔引擎”双重十恶大罪时，扇区高阶大法官/司法元帅（瓦莱丽娅）有权直接召开**战地最高法庭**当场宣判极刑，并在泰拉内政部委派新总督抵达前（边境星区往往耗时数年），设立**法务部要塞法庭（Precinct-Fortress）实行临时司法监护军管**，合法指派维勒斯贤者与米拉组建下巢自治技术行会！

## 五、帝国上巢贵族饮食、珍稀织物与日常生活风物考据（第073—090章五日留驻温存篇精进增补！）

1. **上下巢天壤之别的饮食体系（供烤饼干与庆功宴细节描写）**
   - **下巢平民日常**：终年食用**藻类酵母蛋白砖（Slab）**、真菌蘑菇糊与循环过滤水，从未尝过真正的蔗糖、乳脂黄油与农业世界精磨白面粉。
   - **上巢总督宫特供食材（查抄莫尔丹冷库合法缴获）**：来自花园农业世界的**特级精白小麦粉**、新鲜冷藏**牧场天然黄油与禽蛋**、鲜嫩多汁的**格洛克斯巨蜥牛里脊肉（Grox Fillet，帝国最顶级肉食）**、温室水晶棚栽种的**琥珀蜜柑与紫晶葡萄**。
   - **经典饮品**：帝国军官与贵族最常饮用的陈年蒸馏烈酒**阿玛赛克白兰地（Amasec）**、提神但苦涩的军用**雷卡夫合成咖啡（Recaff）**、以及清香微苦的**坦纳热茶（Tanna）**。
2. **帝国高阶防具织物与服饰礼制（供为米拉裁制新衣与瓦莱丽娅便装描写）**
   - **星蚕防弹丝绸（ Ballistic-weave Mesh Silk）与光学织物（Cameleoline）**：上巢大贵族与审判官常服内衬的高科技微米金属混纺真丝，触感如水般柔滑轻盈，却能抵御酸雨腐蚀与普通匕首劈刺。
   - **神圣有机心火派大技师礼袍**：区别于传统机械教笨重阴森的血红罩袍，米拉就任首席大技师所穿礼服可采用**纯白底色镶嵌赤金太阳齿轮暗纹与火星红滚边**的修身轻礼裙，既合乎《生物贤者正典》纯洁有机之意，又尽显十六七岁少女的明艳俏丽！
   - **高阶大法官常服**：瓦莱丽娅卸下三十公斤重的黑金动力辅助甲壳甲后，内穿修身玄黑高领丝绒常服衬衫与长靴，配披肩银白长发，极具禁欲系帝国女贵族与铁血元帅的反差风韵。
